# Ημερολόγιο Καταγραφής Διατροφής 🍽️

Online πλατφόρμα καθημερινής καταγραφής γευμάτων, βασισμένη στο έντυπο
«ΣΥΝΔΥΑΣΜΟΙ ΤΡΟΦΩΝ» (3άδες & 2άδες).

## Λειτουργίες

- **Ημέρα** — συμπλήρωση των 5 γευμάτων της ημέρας (Πρωινό, Προγεύμα, Γεύμα,
  Απογευματινό, Βραδινό): **ένα ελεύθερο πεδίο ανά γεύμα** («Τι έφαγες;»),
  με την **ώρα** κάθε γεύματος, φυσική δραστηριότητα (είδος/ώρα/διάρκεια),
  νερό σε ml (με κουμπιά +250/+500) και σημειώσεις. Αυτόματη αποθήκευση.
  Παλιές καταγραφές (πολλαπλά πεδία ανά γεύμα, ποτήρια νερού) εμφανίζονται
  αυτόματα συγχωνευμένες — τίποτα δεν χάνεται.
- **Χρήστες** — πολλαπλά προφίλ στην ίδια συσκευή (προεπιλεγμένα: Νίκος, Εύα,
  Άλκης, Μαρία, Δοκιμή), το καθένα με το δικό του ημερολόγιο. Στο άνοιγμα της
  σελίδας διαλέγεις πάντα λογαριασμό· εναλλαγή και από το κουμπί χρήστη πάνω
  δεξιά, δημιουργία νέου χρήστη με ένα όνομα, διαγραφή χρήστη.
  Λογαριασμοί με online σύνδεση προγραμματίζονται για επόμενη έκδοση.
- **Εβδομάδα** — προβολή σε πλέγμα όπως το έντυπο Word.
- **Ιστορικό** — όλες οι προηγούμενες ημέρες με αναζήτηση, φίλτρο μήνα και στατιστικά.
- **Οδηγός** — οι κανόνες συνδυασμών με τις εικόνες του πρωτότυπου εντύπου.
- **Εξαγωγή** — Excel (.xlsx) σε αναλυτική μορφή ή μορφή ημερολογίου, CSV,
  εκτύπωση/PDF και αντίγραφο ασφαλείας JSON (εξαγωγή/εισαγωγή).

## Δεδομένα

Τα δεδομένα αποθηκεύονται **τοπικά στον browser** (localStorage) χωριστά για
κάθε χρήστη, και — με ενεργό online συγχρονισμό — **και στο cloud**
(Firebase Firestore), κάτω από έναν «κωδικό οικογένειας» που ορίζεται
αυτόματα (`diatrofi-2026`) — αλλάζει από Εξαγωγή → Online συγχρονισμός. Κάθε αλλαγή ανεβαίνει αυτόματα
και εμφανίζεται ζωντανά στις άλλες συσκευές· νεότερη αλλαγή ανά ημέρα
υπερισχύει. Χωρίς σύνδεση η εφαρμογή δουλεύει κανονικά τοπικά. Το αντίγραφο
.json παραμένει διαθέσιμο ως εφεδρεία.

**Προστασία δεδομένων**: κάθε διαγραφή (ημέρας, χρήστη, «Διαγραφή όλων»)
αντιγράφεται πρώτα στον «κάδο» του cloud (`trash`) πριν σβηστεί, ώστε να
είναι ανακτήσιμη. Επιπλέον, μία φορά την ημέρα αποθηκεύεται αυτόματα πλήρες
αντίγραφο του ημερολογίου κάθε χρήστη (`backups`, κρατιούνται τα 30
τελευταία). Δεδομένα από την παλαιότερη έκδοση
(χωρίς χρήστες) μεταφέρονται αυτόματα στο προφίλ «Νίκος».

### Ρύθμιση Firebase (μία φορά)

1. [console.firebase.google.com](https://console.firebase.google.com) →
   project **food-diary-cee75** → Build → **Firestore Database** →
   Create database (test mode).
2. Καρτέλα **Rules** → επικόλληση των παρακάτω κανόνων → Publish
   (οι κανόνες test mode λήγουν σε 30 ημέρες, οι παρακάτω όχι):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /families/{family}/{document=**} {
      allow read, write: if true;
    }
  }
}
```

Η πρόσβαση στα δεδομένα προστατεύεται από τον μη-προβλέψιμο κωδικό
οικογένειας (μέρος της διαδρομής στη βάση) — μην τον μοιράζεστε εκτός
οικογένειας. Το `apiKey` του Firebase δεν είναι μυστικό· απλώς
προσδιορίζει το project.
